# Перенос обучения на другой ПК

GitHub используется только для кода. Датасеты и веса модели в репозиторий не загружаются.

## На новом ПК

```bat
git clone <URL_РЕПОЗИТОРИЯ>
cd CutoutNet-Training
install_windows.bat
```

После этого установи CUDA-версию PyTorch командой с официального PyTorch selector и проверь:

```bat
.venv\Scripts\python.exe check_gpu.py
```

Должно быть `CUDA available: True`.

Затем скачай/перенеси P3M-10K отдельно в `data/raw/P3M-10k`, запусти Dataset Wizard, импорт и QA.

Для первой проверки обучения поставь `epochs: 2` в `config/train.yaml`. Если обучение и validation проходят, можно увеличить число эпох.

## Как переносить датасет

Не через GitHub. Варианты: внешний SSD, локальная сеть, облачный диск или повторное скачивание исходного датасета на обучающем ПК.

## Как переносить best.pt обратно

`best.pt` не коммитится. Перенеси файл отдельно и положи на основном ПК в `checkpoints/cutoutnet/best.pt`.
