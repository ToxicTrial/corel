# CutoutNet v0.3 — подключаемые рабочие модули

Этот пакет **накладывается поверх существующего репозитория `ToxicTrial/corel` v0.2.4**. Старые файлы `cutoutnet/model.py`, `trainer.py`, `losses.py`, `dataset.py`, конфигурация основного обучения и обученные веса **не заменяются**. Существующие шесть голов + Fusion и остаточная ROI U-Net уже были реализованы в v0.2.4. Добавлены реальный инференс, Validator, подключение ROI CNN, её отдельное обучение, оценка оригинального разрешения, коррекции пользователя и контур резки SVG.

## Установка на Windows

1. Скопируйте содержимое архива в корень своего клона `corel` с объединением каталогов. Файлы старой версии заменять не требуется.
2. В терминале корня проекта установите прежние `requirements.txt`, CUDA PyTorch по инструкции проекта.
3. Для работы нужна **уже обученная** основная сеть (`best.pt` или `last_full.pt`). Случайных весов в этом пакете нет.

## Первый прогон (пока ROI Refiner не обучен)

```powershell
python cutout.py "C:\images\test.jpg" --checkpoint "C:\CutoutNet\last_full.pt" --output outputs --diagnostics --cut-svg --dpi 300 --offset-mm 2
```

В Google Colab текущий чекпоинт основного обучения ранее сохранялся в:
`/content/drive/MyDrive/CutoutNet/checkpoints/t4_640/last_full.pt`.
Это путь в Google Drive, а не файл, включённый в архив. Извлеките или примонтируйте его перед запуском.

Текущий чекпоинт содержит веса основной сети. Если обучены лишь первые 7 эпох, модель ещё может ошибаться; параметры `dice` на валидации не гарантируют качество сложных стикеров.

## Обучение ROI Refiner

```powershell
python -m cutoutnet.refiner_train --train-root data/cutoutnet/manifests/train.jsonl --val-root data/cutoutnet/manifests/val.jsonl --output checkpoints/refiner --crop 512 --epochs 20 --batch-size 2
```

Refiner использует изображения и маски исходного разрешения, случайные ROI вокруг границ, искусственные ошибки маски. Эти синтетические ошибки дают рабочий старт, но **не гарантируют** улучшение CutoutNet: обязательно сравнивать результаты с включённым и выключенным Refiner на отложенном тестовом наборе. Для промышленного качества после этого потребуется обучение на фактических ошибках основной сети.

После тренировки:

```powershell
python cutout.py "C:\images\test.jpg" --checkpoint "C:\CutoutNet\last_full.pt" --refiner checkpoints/refiner/best.pt --output outputs --diagnostics --cut-svg
```

ROI-патчи по умолчанию 512×512 с перекрытием 128. Максимум 80 ROI на фотографию; изменяется `--max-rois`. Пиксели вне ROI остаются результатом основной сети. **Включать ROI Refiner без подготовленного чекпоинта нельзя**.

## Объекты, отверстия и формат наклеек

- Результат `*_cutout.png`: исходный RGB и альфа строго 0/255; все прогнозируемые компоненты сохраняются. Отверстия не заполняются автоматически.
- `*_cutline.svg`: необязательная физическая траектория резки; прозрачные внутренние отверстия **не вырезаются**, если требуется отдельная внутренняя резка — это другая настройка печати.
- `--cut-mode separate` строит контур для каждого компонента, `unified` строит **выпуклую общую оболочку** (она может оставлять большие поля между далёкими объектами).
- `--dpi` обязательно должен соответствовать реальному размеру печати, иначе отступ `--offset-mm` будет неверным.
- Для обработки папки передайте её вместо одного файла.
- Alpha физически бинарная, поэтому полупрозрачность и сглаженный край не поддерживаются. Цветовой ореол в RGB у края не устраняется отдельной color-decontamination CNN.

## Оценка качества в исходном разрешении

```powershell
python evaluate_v03.py --checkpoint "C:\CutoutNet\last_full.pt" --data data/cutoutnet/manifests/test.jsonl --output outputs/eval_before.json
python evaluate_v03.py --checkpoint "C:\CutoutNet\last_full.pt" --refiner checkpoints/refiner/best.pt --data data/cutoutnet/manifests/test.jsonl --output outputs/eval_after.json
```

Рассчитываются IoU, Dice, Boundary-F1, Component Recall, Hole-IoU и количество ложных/пропущенных пикселей. Контурные и топологические метрики — диагностические приближения, а не замена визуальному контролю.

## Накопление исправлений

```powershell
python register_correction.py --image "C:\images\test.jpg" --mask "C:\images\edited_mask.png"
```

Сохраняет проверенную пару в `data/cutoutnet/corrections/`, не добавляя её автоматически в обучающий manifest и не переобучая модель. Исправленная маска обязана содержать только 0 и 255.

## Совместимость и ограничения

- Основная модель v0.2.4 и checkpoint `last_full.pt` остаются побайтно совместимы; из них загружаются `model`, `model_config`, `image_size`.
- Сохраняется возможность продолжить основной тренинг через `python train_colab.py`, `resume: auto`, с 8-й эпохи после сохранённой 7-й.
- Обучение новой ROI CNN происходит отдельно. Веса ROI Refiner **пока отсутствуют**, если вы не запустили отдельную тренировку.
- Включение сторонних checkpoint неизвестного происхождения небезопасно: `torch.load(weights_only=False)` используйте только для собственных доверенных файлов.
- Objectness Head в существующей модели — карта центров компонентов, не полноценная instance segmentation. Автоматическое определение намерения «что оставить» в неоднозначных сценах пока не реализовано.
- Для действительно высокого качества на волосах/прозрачных границах понадобятся дополнительные эталонные данные и отдельное обучение/сравнение моделей.
